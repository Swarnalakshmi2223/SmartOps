# SmartOps Frontend

The SmartOps frontend is a React application powered by Vite.

## Requirements

- Node.js 18 or newer
- npm

## Installation

```powershell
cd Frontend
npm install
```

## Development

Start the Vite development server:

```powershell
npm run dev
```

Vite will print the local development URL in the terminal.

## Available Commands

- `npm run dev` - Start the development server with hot module replacement
- `npm run build` - Build the application for production
- `npm run lint` - Run ESLint
- `npm run preview` - Preview the production build locally

## Current UI

The current application uses the Vite and React starter interface while the SmartOps screens and workflows are being developed.

## Main Technologies

- React
- Vite
- React Router
- Axios
- React Icons
